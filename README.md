# Fitness by Poushka Lova Lova

Diffusion des versions de l'application Android.

Ce dépôt ne contient pas le code source : seulement les APK publiés et le fichier
`version.json`, que l'application lit pour savoir si une version plus récente existe.

L'installation se fait depuis l'application elle-même, dans Réglages, section Mise à jour.
